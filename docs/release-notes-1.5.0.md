## Watson 1.5.0

**Free. No account. One file.**

A start-up release. The search flow is unchanged; the Windows build is the part that moved.

### How to start

1. Download **Watson-1.5.0-portable.exe** — from [watsonfind.icu](https://watsonfind.icu) or from the asset below. Both are the same build.
2. Double-click it. If Windows shows a blue warning, click **More info**, then **Run anyway**.
3. Type a nickname, email, phone or website and press **Enter**.

Step-by-step pictures are in the [README](https://github.com/vaishantsah/watson-AI-osint-all-in-one#install-in-2-minutes). Website: [watsonfind.icu](https://watsonfind.icu).

### What's new

- **Faster cold start** — the app no longer unpacks itself into a temp folder on first run; the window is up and the first search runs straight away.
- **One install location per user** — `%LOCALAPPDATA%\Programs\Watson`. Upgrading keeps your history and settings in place instead of starting over in a new temp folder each time.
- **Cleaner window** — the query field, the result list and the footer sit on one grid, so long handles no longer push the status line off the row.
- **Fewer false positives** — the identity score ignores accounts whose only match is a shared avatar.
- **Smaller download checks** — the download page and the release now carry the same SHA-256, so you can verify the file you got.

Full list: [CHANGELOG.md](https://github.com/vaishantsah/watson-AI-osint-all-in-one/blob/main/CHANGELOG.md).
